# 安全、可追溯与发布治理

## 最小权限
Agent 仅能提出工具调用方案；执行器以 allowlist 暴露张量、数据、前向预算和目录。基座 checkpoint 只读；禁止未经授权的外部网络、隐式模型上传和任意路径写入。

## 修改约束
原作者 Exp 8 禁止修改 embeddings、输出头、最终 norm 及整张量纯缩放。本项目 R1 复现应尊重其研究约束；若在 R4 使用不同约束，必须独立标记协议，不宣称严格复现。

## 验收与回滚
1. 检查每个变更张量的前后哈希、形状和 dtype；
2. 检查没有被允许列表之外的修改；
3. 冻结补丁后进行独立基线与非目标评测；
4. 报告 Right-to-Wrong、格式错误、异常重复、空白输出和成本；
5. 超过回归阈值则 REJECT；有任何无法复核的证据则 NO EDIT；
6. 发布只提供 manifest / diff 和回滚路径，不默认覆盖原始模型。

## 负面结果与科学诚信
每个执行失败、归因无效、效应不稳定、随机对照优于目标干预都要保存。数据/模型不可用时报告不可用，不补造“测试已通过”。未实现的占位文件不得被文档、README 或自动任务标成 production ready。

## 安全对齐相关研究
机制可解释性可以帮助理解模型行为，但本项目的默认目标是**可靠性、异常诊断与防御性审计**，不把移除安全拒答、规避限制或自动化破坏作为交付目标。任何安全实验应在隔离和合规评审下进行，且不发布可直接绕过防护的编辑方法。
