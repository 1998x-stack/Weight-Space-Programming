# 方法横向比较：优化目标和证据等级

| 方法 | 对象 | 主要目的 | 人类/Agent 决策 | 注意事项 |
|---|---|---|---|---|
| SGD/AdamW/LoRA | 梯度驱动权重更新 | 学习能力或调整行为 | 人类设计损失与训练 | 训练成本、数据污染、灾难性遗忘 |
| ROME | 局部 MLP 权重 | 编辑个别事实 | 研究者定义定位与更新 | 事实可定位假设 |
| MEMIT | 多层 FFN 权重 | 批量事实编辑 | 研究者设计算法 | 多记忆干扰 |
| Activation steering / RepE | 推理时隐藏状态 | 引导特定行为 | 选择表示方向 | 推理时生效，不一定持久 |
| SAE analysis | 稀疏表征字典 | 提取可解释特征 | 训练/选择 SAE | 引入新模型与额外代价 |
| Exp 8 WSP | 两层 MLP 的特定输出列 | 修复重复推理 | 通用 LLM 提案与验证 | 还未显示跨模型可靠性 |
| Neural compilation | 网络权重 | 将显式规则转为网络计算 | 人工/LLM 分解程序 | 规则未知时局限明显 |

## 重要区别
**编辑能力**（是否能修改参数）、**解释能力**（是否准确描述机制）、**学习能力**（是否获得新知识）、**泛化能力**（是否跨任务有效）是四个不相等的概念。

## 未来公平实验
Qwen Exp 8 应至少比较：原始参数 + 作者解码、原始参数 + 官方解码、编辑参数 + 两种解码、Thinking Off 双模型、基于 prompt 的终止策略（作为应用层基线）、预算匹配的训练基线（若许可）。不允许把不同输出长度或不同评分器下的分数直接比较成算法提升。
