# 负面结果与局限性（比成功率更重要）

## Gemma 3 270M
原始报告：数学能力低，但只有约 8.5% 的输出触及长度上限，与 Qwen 的 93.0% 不同。随着可用前向预算从 5、10、25 到 50，MATH-500 从基线 6.8% 仅到约 7.0/7.6/7.7/7.0%，无可靠大幅提升。**不要把两模型实验解释成“某种架构必然不能编辑”**；它测试的是具体目标、预算、模型与提案搜索过程。来源：[Gemma follow-up](https://github.com/RikiyaT/lm_understand-logs/tree/main/exp8_math/gemma_followup)。

## Exp 7 — Sycophancy
观察：纯静态权重比较尝试未建立可靠识别；加入注意力探针后表现明显改善。可推断静态参数差异与自然语言行为语义之间没有普遍的直接对应关系；不能据此宣称只看权重就能自动审计全部行为。

## Exp 2 — Diffusion
研究者辨识出几何形状的边界，但误判实心内容。这是“识别结构 ≠ 完整模拟模型生成行为”的例子。

## Exp 5 — MinAtar
Breakout：研究报告 517.4，PPO 500M 步 25.3；但 Seaquest 53.1 vs PPO 88.9，Asterix 53.2 vs PPO 55.2。不能抽取一个 20× 的成功数字概括全部环境。[原始博客](https://rikiyat.github.io/blog/weight-space-programming/)。

## Exp 8 — 编辑副作用
虽然截断问题大幅减少，部分生成可能转为其他无效输出；独立复测 Thinking Off 下的 MATH-500 由 45.8 降至 43.6。应加入 whitespace runaway / EOS / 格式 / 非目标任务等自动分解。

## 研究设计启示
1. 先把失败原因分类再选择技术，而不是先选择权重编辑。
2. 独立评测原始推理模式、关闭思考模式和模型卡推荐采样。
3. 每个被报告的成功案例都应有预算匹配的负例和基线。
4. 明确允许“无可靠编辑，提交 No-Edit 结论”。
