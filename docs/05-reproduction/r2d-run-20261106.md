**Important reproducibility finding:** after loading and comparing the actual token-ID arrays, each of the four 96-token sequences is a bitwise-exact prefix of the corresponding 256-token sequence (4/4). This supports interpreting the changed output lengths as a budget-only *observational* comparison in this fixed deterministic setup, not as an algorithm or model change.

The 256-token repetition candidate appears in **arithmetic-c** (9 × 7): motif period = 6 token IDs, repeated 3 times (18-token span), starting at generated token index 233 (0-based). The visible excerpt is from the model's attempted visual column multiplication with repeated short lines. It may be formatting repetition, not a sustained pathological reasoning loop. Our exact token detector gives a **candidate**, not a causal label.

Neither run can establish mathematical correctness: boxed marker only indicates the character pattern occurs somewhere, potentially in analysis of the request. No scored answers, valid loop-gold labels or holdout evaluation exists. The large percentage of length cutoffs is strongly conditional on the very small output caps (both are far below the original study's maximum 32,768 new tokens).

## Run local, auditable budget comparison

Retrieve both official trace artifact ZIPs (or independently generate fresh outputs under the frozen settings), extract their traces.json to separate paths and run:

    python scripts/r2d_compare_budgets.py \
      --short /runs/r2d/96/traces.json \
      --long /runs/r2d/256/traces.json \
      --out /runs/r2d/budget-comparison.json

The comparator rejects mismatched model hashes, source prompt hashes, decoding configs, changed per-record text SHA, incorrect classification and any nonidentical token prefix. It never fabricates a missing output or turns a token repetition motif into a verified mechanism. The comparison CLI is a new reusable code deliverable; the table above was independently checked directly against the downloaded actual run archives.

## Blocked scientific gates

1. Sample genuinely challenging tasks (rather than only four trivial handwritten questions) under separately preregistered decoding profiles, including the authors' settings where the open harness allows; preserve exact generation/finish reasons and human-reviewed loop labels.
2. Create independent matched productive/repetitive prefixes from **observed model trajectories**, control context length/position and freeze discovery/validation/holdout splits.
3. Probe both Qwen layers 15/19 under controlled conditions; compare no-edit/random/label-swap/one-layer/two-layer interventions and record generation-level behavioral regressions.
4. Independently run full R1 base vs p50c MATH-500 500×4 GPU evaluation and issue reproducible paired statistics; do not import the original author's published scores as new results.
5. Do not claim R2 mechanism rediscovery or "repeat problem fixed" from these pilot traces.
